1. Goal

Publish the existing Python MCP server at an Azure endpoint:

https://YOUR-APP-NAME.azurewebsites.net/mcp
Key point: Local Inspector uses stdio. Azure uses streamable-http. Do not deploy run_inspector.bat as the web server.

4. Configure the Streamable HTTP server

Replace src\mcp_demo\http_server.py with:

"""Run the MCP server over Streamable HTTP locally or in Azure."""

import os

from mcp.server.transport_security import TransportSecuritySettings
from mcp_demo.server import mcp


def allowed_hosts() -> list[str]:
    hosts = [
        "localhost",
        "localhost:*",
        "127.0.0.1",
        "127.0.0.1:*",
    ]

    azure_hostname = os.getenv("WEBSITE_HOSTNAME", "").strip()

    if azure_hostname:
        hosts.extend([azure_hostname, f"{azure_hostname}:*"])

    return hosts


security = TransportSecuritySettings(
    enable_dns_rebinding_protection=True,
    allowed_hosts=allowed_hosts(),
    allowed_origins=[
        "http://localhost:6274",
        "http://127.0.0.1:6274",
    ],
)


if __name__ == "__main__":
    port = int(
        os.getenv(
            "PORT",
            os.getenv("WEBSITES_PORT", "8000"),
        )
    )

    mcp.run(
        transport="streamable-http",
        host="0.0.0.0",
        port=port,
        streamable_http_path="/mcp",
        json_response=True,
        stateless_http=True,
        transport_security=security,
    )
The Azure hostname must be allowlisted. Without this, a deployed server can return 421 Invalid Host header.

6. Create a clean Azure deployment folder

Run from the project root:

New-Item -ItemType Directory -Path azure_deploy -Force

Copy-Item requirements.txt azure_deploy\
Copy-Item pyproject.toml azure_deploy\
Copy-Item src azure_deploy\src -Recurse -Force
Copy-Item data azure_deploy\data -Recurse -Force

Required structure

azure_deploy
├── requirements.txt
├── pyproject.toml
├── data
│   ├── employees.json
│   └── inventory.json
└── src
    └── mcp_demo
        ├── __init__.py
        ├── server.py
        └── http_server.py
VS Code: Select File → Open Folder and open azure_deploy. Do not deploy .venv, tests, or local cache files.

8. Configure App Service

Add application settings in VS Code

Azure sidebar → App Services → expand your app → right-click Application Settings → Add New Setting.

NameValuePurpose
SCM_DO_BUILD_DURING_DEPLOYMENTtrueInstall requirements during deployment.
WEBSITES_PORT8000Internal application port.
PYTHONPATH/home/site/wwwroot/srcMake the MCP package importable.

Set startup command from VS Code terminal

az login
$RG = "rg-mcp-demo"
$APP = "YOUR-UNIQUE-WEB-APP-NAME"
az webapp config set --resource-group $RG --name $APP --startup-file "python -m mcp_demo.http_server"

If Azure CLI is unavailable: right-click the app → Open in Portal → Settings → Configuration → General settings → Startup Command:

python -m mcp_demo.http_server

13. Production security

Warning: The classroom server has no user authentication. Never expose confidential business data through it.
  • Add MCP-compatible OAuth for real users.
  • Use App Service access restrictions.
  • Store secrets in Azure Key Vault.
  • Use managed identity.
  • Enable Application Insights.
  • Require human approval for write, delete, purchase, and messaging tools.

Stop the demo

az webapp stop --resource-group $RG --name $APP

14. Deployment checklist

Quick knowledge check

Which transport should be deployed to Azure?

Streamable HTTP. stdio is for local subprocess-based servers.

Why configure PYTHONPATH?

The project package is under src, so Azure must include that directory when importing mcp_demo.
