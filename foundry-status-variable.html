⚡ Share one variable: status

🧠 Planner → 📦 Local.status → 🔎 Extractor
Idea: Planner sets status → Extractor reads Local.status.
1

Open the workflow

Foundry portal → Build → Workflows → open your workflow.

2

Planner outputs status

Click the Planner node → set its output to this JSON schema → name it status.

{
  "type": "object",
  "properties": {
    "status": { "type": "string" }
  }
}

Now it's available as Local.status.

3

Extractor reads status

Click the Extractor node → in its prompt/input, use:

Current status: Local.status
4

Save & run

Click Save (no autosave) → Run Workflow → check that Local.status shows the Planner's value.

Keep the Local. prefix. Save creates a version. Foundry Workflows visual designer.
